Completed projects

  1. Drawing fractals using OpenGL and C++ (Github link)

    An old project as part of high school mathematical research on Schottky groups and fractals. In order to visualise the fractals generated to get a better understanding, I built a program in C++ that wrote an Asymptote (programming language used in concurrent with LaTeX occasionally to generate high-quality images) file that would compile into a PDF showing the fractal, original project link here. Later due to memory constraints on my old Macbook Pro (~8GB RAM which would blow by the time we reached 12 levels of recursion), I switched Asymptote for OpenGL, along with floating-point for arbitrary-precision, to get a much faster and accurate renderer. Eventually managed to implement and include the cusp algorithm to plot the once-degenerate groups.

    Languages used: C++, GLSL (later iteration)

  2. Sequential processor (university project) (Github link)

    A university project (ELEC2602, Digital Logic) to implement a simple processor in Verilog; no pipelining or vectorisation! Program memory however is preloaded from an ASCII binary file. Project also includes its own assembler in Python.

    Languages used: Verilog (processor), Python (assembler)
