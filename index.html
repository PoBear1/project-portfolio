Miscellaneous repositories

  1. Drawing fractals using OpenGL and C++ (Github link)
    An old project as part of high school mathematical research on Schottky groups and fractals. In order to visualise the fractals generated to get a better understanding, I built a program in C++ that wrote an Asymptote (programming language used in concurrent with LaTeX occasionally to generate high-quality images) file that would compile into a PDF showing the fractal, original project link here. Later due to memory constraints on my old Macbook Pro (~8GB RAM which would blow by the time we reached 12 levels of recursion), I switched Asymptote for OpenGL, along with floating-point for arbitrary-precision, to get a much faster and accurate renderer.
